# IBM Bid Skills — Bob BYOS Pack

33 IBM Bid & Tender skills for IBM Process Studio. Covers the full bid lifecycle: qualification, hot buttons, win themes, requirements analysis, strategic positioning, solution architecture, writing, social value, legal, staffing, pricing, and TDA review.

## How to connect in IBM Process Studio (BYOS)

1. Go to **Settings ? Skills ? Bring Your Own Skill (BYOS)**
2. Repository URL: `https://github.com/Grace9393/grace-bob-bid-skills`
3. Branch: `main`
4. Folder: `/` (root)
5. Enter your GitHub PAT and click **Connect**

> **Note:** Each subfolder is one skill. The folder name must match the `name:` field in its `SKILL.md`.
