# G-Cloud Framework Assessment Criteria

G-Cloud 14 framework-specific legal risk assessment questions.

## Framework Overview

G-Cloud is a pan-government framework for cloud hosting, software, and support services. Characterised by simple call-off process, standard terms, and SME-friendly approach.

## Key Differences from DOS6

- **Pure cloud focus**: SaaS, PaaS, IaaS only
- **Simplified contracting**: Standard call-off terms, limited negotiation
- **Lower value threshold**: Individual purchases typically <£100K
- **Framework terms non-negotiable**: Customer can only add, not remove obligations
- **Pricing transparency**: Public pricing on Digital Marketplace
- **Terms standardisation**: Heavily standardised liability and IP provisions

### 2. Liability Caps, Indemnification, IP Ownership

**G-Cloud Context**: Framework establishes 100% total contract value liability cap. Cannot be increased in call-offs. IP in SaaS remains supplier property with licence to customer.

## Risk Classification - G-Cloud Specific

**RED FLAGS for G-Cloud**
- Call-off attempting to override framework liability caps
- Data sovereignty requirements incompatible with multi-region architecture
- Customer adding warranties beyond framework (SLA guarantees become warranties)
- Unlimited audit rights added at call-off level
- IP transfer requirements added to SaaS

**AMBER for G-Cloud**
- Total contract value >£5M (low liability cap relative to value)
- Multi-year commitments without break clauses
- Data processing outside EEA without adequacy decision
- Cyber Essentials Plus requirement with short implementation timeline
- Bespoke development added to SaaS call-off
