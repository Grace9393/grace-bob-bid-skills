# Special Pricing Scenarios

## Framework Agreements

**Structure:** Pre-agreed rate cards for call-off work over 2-4 years.

**Pricing:**
- Fixed day rates by role/seniority
- Rates locked 12-24 months, then CPI adjustment
- Volume discounts for minimum spend commitments

**Example:**

| Role | Year 1-2 | Year 3 (CPI) |
|------|----------|-------------|
| BA Senior | £950 | £976 |
| Dev Senior | £900 | £924 |

## Managed Service Pricing

**Per-User Model:**
```
Monthly Fee = Users × £15/user/month
1,000 users = £15k/month = £180k/year
```

**Service Catalog:**
```
Base: £75k/month (8×5 support, 3 environments)
Add-ons:
- 24×7 support: +£15k/month
- Extra environment: +£5k/month
- Enhanced SLA: +£10k/month
```

**SLA Credits:**

| Breach | Credit |
|--------|--------|
| <99.5% availability | 5% monthly fee |
| P1 >4hrs | 2% per breach |

Cap: 20-30% of monthly fee

## Gain-Share Pricing

**Structure:**
```
Payment = Base Fee + (Share % × Verified Savings)

Example:
Base: £500k
Share: 50% of savings
Savings: £2m
Total Payment: £500k + £1m = £1.5m
```

**Requirements:**
- Agreed baseline before start
- Independent verification
- Cap at 150-200% of base fee
- Measurement period: 12-36 months

## Risk/Reward Pricing

**Structure:**
```
Base: £1m
Bonus/Penalty: ±20%
Range: £800k - £1.2m
```

**Example KPIs:**

| KPI | Weight | Bonus/Penalty |
|-----|--------|---------------|
| On-time delivery | 30% | ±£60k |
| Within budget | 30% | ±£60k |
| User adoption >80% | 20% | ±£40k |
| Defect rate <5% | 20% | ±£40k |

## Volume/Tier Pricing

**All-Units Discount:**
```
0-1,000 hrs: £100/hr
1,001+ hrs: £90/hr (applies to ALL hours)

Usage: 1,500 hrs
Payment: 1,500 × £90 = £135k
```

**Marginal Discount:**
```
0-1,000 hrs: £100/hr
1,001+ hrs: £90/hr (only excess)

Usage: 1,500 hrs
Payment: (1,000×£100)+(500×£90) = £145k
```

**Volume Rebates:**
```
Pay £100/hr all year
If >5,000 hrs used: 10% year-end rebate
```

## Multi-Year Efficiency Pricing

| Year | Cost | Discount | Rationale |
|------|------|----------|----------|
| 1 | £1.2m | - | Setup/learning |
| 2 | £1.08m | -10% | Efficiency gains |
| 3 | £1.02m | -15% | Automation |
| 4+ | £1.05m | -12.5% | +CPI adjustment |

**Efficiency Drivers:**
- Year 1→2: Team onboarded, processes optimized
- Year 2→3: Automation deployed, tickets reduced
- Year 3+: Steady state with CPI adjustments
