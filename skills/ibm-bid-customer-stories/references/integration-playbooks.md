## Integration with Other Skills

**Typical Workflow**:

1. `ibm-bid-requirements-analysis` - Understand requirements
2. `ibm-bid-customer-stories` - Find relevant proof points (this skill)
3. `ibm-bid-library` - Find technical approaches
4. `ibm-bid-strategy-and-capabilities-2026` - Current positioning
5. `ibm-bid-writer` - Draft response
6. `ibm-bid-answer-evaluator` - Assess quality

This skill works best when combined with:
- **ibm-bid-writer**: Use customer stories as proof points in tender responses
- **ibm-bid-strategy-and-capabilities-2026**: Align customer stories with current IBM capabilities and strategy
- **ibm-bid-answer-evaluator**: Reference customer stories when evaluating whether a response demonstrates sufficient evidence
- **ibm-bid-win-themes**: Search for success stories with quantified outcomes when developing win themes (Step 4 of Shipley process)
- **ibm-bid-requirements-analysis**: Provides sector context to help identify relevant customer stories

## Skill-Specific Search Strategies

When supporting other skills, use these tailored search approaches:

### For ibm-bid-win-themes (Win Theme Development)

Focus on **quantified outcomes** to support the Shipley formula:
- Search for: percentage improvements, cost savings, time reductions
- Keywords: "reduction", "improvement", "savings", "increase", specific metrics
- Prioritize: Stories with multiple quantified benefits that can substantiate discriminating features

### For ibm-bid-writer (Response Drafting)

Match **industry + cloud + use case** to client requirements:
- Search by: Client's industry sector first, then filter by relevant Salesforce clouds
- Keywords: Industry names, specific cloud platforms, use case terminology
- Prioritize: Stories from same/similar industry with comparable scale

### For ibm-bid-answer-evaluator (Evidence Verification)

Verify **specific company references** exist:
- Search for: Exact company names mentioned in responses
- Confirm: Outcomes quoted match database entries
- Flag: Any claims that cannot be substantiated

### For ibm-bid-requirements-analysis (Context Gathering)

Identify **sector patterns** and common challenges:
- Search by: Industry/sector keywords from tender document
- Look for: Common challenges and outcomes in that sector
- Note: Typical Salesforce solutions deployed for similar organizations
