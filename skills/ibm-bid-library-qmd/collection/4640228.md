IBM uses Kubernetes at the Home Office to deliver highly available, scalable, secure and resilient applications based on containers and operating on a cloud-hosted platform. IBM is also delivering and optimising a full microservices-based architecture and capability for a major European Bank -building new core banking capabilities on AWS. IBM has designed and built full infrastructure services to develop, test and operate cloud-native applications using EKS and other AWS services, addressing non-functional requirements including security (including container image security), scaling, high-availability across availability zones and resilience, supporting zero downtime. These patterns will support an end-to-end API and microservices-driven transformation.
