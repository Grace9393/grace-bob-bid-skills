For a UK bank, IBM built an AWS-based data fabric accepting JSON/ XML messages via Kafka streams and can acquire and integrate batch data to produce marts consistent with Lambda architectures. The capability to combine real-time and batch data is new for this bank and viewed as a key component for the future fully digital organisation. IBM was an early adopter of Lamda-style Batch, Message and Streaming Data Acquisition architectures, developed using our experience of real-time inbound marketing decisioning (Chordiant(PEGA)/Unica/SAS) driven from data warehouses and lakes. Our big data architectures and assets include Lambda components bridging batch and real-time zones.
