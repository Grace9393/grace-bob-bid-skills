The IBM Maximo Application Suite Manage application provides the ability to associate any number of meters to an asset. The meter values can be updated either manually during the work execution process through a work order or an inspection form or via the IoT integration from the Maximo Monitor application.
 
The manual entry option still allows for condition-based alerts to be raised using the condition monitoring application with Maximo Manage allowing for Low or High value trigger points. For example, a motor with a temperature meter attached could trigger a work order to be generated if the value entered is above a certain value.
 
An alternative to the above manual entry method is to use the Maximo Monitor application which is also part of the Maximo Application Suite to collect the asset sensor data through the IoT Platform and present this data using configurable dashboards with the ability to identify anomalies in the data. An example dashboard is shown below:
 
Based on the visualisation of this data, a user can review any alerts and take action such as creating a work order against the asset to perform an inspection to try and prevent any unscheduled downtime.
 
The data gathered by the Monitor application can also be used in conjunction with additional data from the core asset record to provide a more holistic view of an asset’s health by using the Maximo Health application.
 
The Maximo Health application is focused on the role of a Reliability Engineer and allows the user to review the overall asset’s health, risk and criticality scores, based on drivers that are defined for each asset class.

The image on the left is an example of a Pump asset in Maximo Health.
For this class of asset the health score is derived from 3 drivers:
 
- Remaining useful life
- Open work
- Meter values
 
 
 
In addition, the values for Criticality and Risk are also calculated using formulas which would be defined by Scottish Water and applicable to the asset classification.
 
As the data volume and quality of data increases, the Maximo Predict application is able to use predictive models to calculate the predicted next failure date of the asset. The Maximo Predict application is made available with 5 out of the box models with the ability for Scottish Water to create additional models where required.

The asset timeline can also be visualised and includes failure data as well as any Preventive Maintenance (PM) schedules, inspections and work orders in the Maximo system:
 
In the example on the left, we can see that the next predicted failure event will occur before the next scheduled PM. This information is critical in ensuring that action is taken prior to the next scheduled PM to prevent any unscheduled asset downtime. This could be either to bring the scheduled PM forward or generate a work order to carry out an ad-hoc inspection. 
 
 
 
With regards to asset stock/inventory optimisation, the IBM Maximo Manage application contains a module for Inventory Management including storerooms, item master details, inventory stock holdings at bin, lot and condition levels if required, re-order processing, reservations, issues, returns and transfers between storerooms. This enables a full view of the inventory availability and ensures you have the stock to hand at the right time to complete work.
 
More advanced capabilities are available in relation to inventory analytics with the IBM Maximo Maintenance, Repair and Operations (MRO) Inventory Optimisation solution. This can help you optimise your maintenance, repair and operations inventory by providing an accurate, detailed picture of performance. The MRO Inventory Optimisation closed-loop solution integrates with the IBM Maximo Application Suite applications, automating day-to-day manual tasks. Machine-learning algorithms gain knowledge from new transactions and movement records and use data to determine, in real time, if the current stocking strategy is still appropriate. Considering past material usage and future demand, the solution helps balance the costs of holding inventory against new orders.
