We are building Scottish Government's new benefit system. Ensuring simplicity and reusability, a squad designed and built two Microservices in Java using Sprint Boot (Spring Ecosystem). We deployed DynamoDB to provide a NoSQL Service which actively controls state locking for our Terraform scripts. One Microservice makes use of Amazon RDS Aurora Database and is PostgreSQL compatible. We created a Postcode lookup Microservices used 12,000 times a day by citizens to quickly select their address; and an adaptor Microservices used 4800 times a day to translate XML to JASON between the digital channel and the case management system.
