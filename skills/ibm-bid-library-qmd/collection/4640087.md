IBM was among the first providers to develop blueprints for landing zone deployment across hyperscalers and iterate with AWS and Microsoft. Our managed landing zone model deploys subscription based environment updates based on new AWS and Azure designs. At Cathay Pacific, IBM migrated 117 critical applications in 20 months. We defined multicloud landing zone deployment models, working with AWS/Microsoft architects and client product owners to develop and support the DevOps pipeline with AWS Code commit and Azure DevOps. We iterated to address end-of-life and service concerns, improve resilience, mitigate risks and reduce outages with ITSM tooling (IBM Klarity, ServiceNow integration).
