A time series is a set of time-stamped data. Types of time series data vary enormously, for example, electricity usage that is collected from smart meters, stock price and trading volumes, ECG recordings, seismograms, and network performance records. The types of queries performed on time series data typically include a time criterion and often include aggregations of data over a longer period. For example, you might want to know which day of the week your customers use the most electricity.
 
ENWL will need the following capabilities to store and analyse time series data:
- Define the structure of the time series data
- Control when and how often data is accepted:
- Set the frequency for regularly spaced records
- Handle arbitrarily spaced records
- Control data storage:
- Specify where to store data
- Change where data is stored
- Monitor storage usage
- Connect with other enterprise / external data
- Load data from an IoT device, IoT platform or a file 
- Query data:
- Extract values for a time range
- Find null data
- Modify data
- Display data in standard relational format
- Analyse data:
- Perform statistical and arithmetic calculations
- Aggregate data over time
- Make data visible or invisible
- Find the intersection or union of data
