Financial and operational considerations in enabling Evergreen IT  
We will use our Cloud Value Transformation (CVT) model to determine the technology roadmap that delivers best business value for you using the following tiered approach to reducing TCO: 
- reduce run costs by reducing the on-premise IT footprint and lower the TCO. With these savings, there are opportunities for re-investment into process automation and application consolidation 
- switch from an annualised budget to a more flexible model to adapt to public cloud variances, and 
- over time, transition from CAPEX to OPEX, with most of the applications on cloud and a small footprint of traditional IT. 
There are options for traditional IT within data centres and CoLo: 
- data centre leasing (or CoLo) - in this model, you can lease a Tier3 CoLo for interim or long-term use, addressing one of the “Sea of Red” challenges to exit an existing data centre 
- pay-per-use/PAYG - using technologies like GreenLake or a managed CoLo provides the option of pay-per-use/PAYG for infrastructure
- private cloud - suited for applications which cannot be migrated to public cloud but utilise consumption-based billing, yielding some cloud platform benefits but with a level of isolation. 
Cloud provides more options to optimise costs, with examples including: 
- consumption-based billing - there are several services for flexing of capacity for variable workloads including auto-scaling, PaaS (Kubernetes clusters on RHEL OpenShift) or serverless. We will use environments for dev/test, created and destroyed as required and base on consumption only 
- resource reservations for constant workloads - for applications with constant workloads, we recommend using reserved instances, saving up to 65% of compute costs 
- spot pricing for low-priority background tasks - low priority tasks which can be pre-empted and not tied to time bound SLAs can make use of spot pricing
- use of hybrid licences - there are opportunities to save license costs on the cloud by utilising the enterprise license agreements and taking advantage of a hybrid license. 
SaaS and PaaS provide true consumption-based billing for workloads which need to be scaled occasionally. 
Operational approaches depend on the hosting destination and the application platform: 
- for legacy applications in traditional IT, bespoke operational scripts will be required 
- containerised custom applications which are on-premise and on cloud will use a consistent set of tooling, and operations will be based on Site Reliability Engineering (SRE) principles 
- managed services on cloud and SaaS/PaaS use a model where some operational responsibilities are with the vendor.
