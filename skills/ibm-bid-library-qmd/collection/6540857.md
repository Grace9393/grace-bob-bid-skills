For Audi's new website platform, IBM developed and managed infrastructure monitoring using AWS CloudWatch. Agents run on EC2 instances, collect system metrics and push to Cloudwatch, integrated with SNS to notify subscribers; setup AWS ECSpps/DevOps pipelines to send alarms and notifications. IBM has experience with Cloud-scale, monitoring and incident alerting tools including Instana, Dynatrace, AppDynamics, OpsGenie, JIRA Service Management, Splunk IBM Redhat Experiential Squads, offer customers Openshift clusters on trial with Datadog agents installed, to monitor Kubernetes instances for cluster performance and API calls. With automated post provision installation, Datadog agents pick up anomalies and create tickets on Service Now.
