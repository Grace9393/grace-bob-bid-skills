Working on Live Systems & Integration into Existing Systems
IBM has extensive experience in deploying RPA solutions across various environments. Our approach is both tailored and principled, ensuring we meet the operational and technical needs of each force while adhering to governance and security standards.
We have a proven track record of deploying and managing RPA solutions in live operational environments, ensuring minimal disruption to critical police functions. Before deployment, we go through multiple phases of testing as shown in Figure1, adapted to the force's requirements e.g., performance testing may only be required on critical systems such as Niche and Storm.

Figure 1: Example Testing Phases
 
Once testing is approved, the deployed process enters hyper-care, where we monitor agreed success criteria before transitioning to BAU. This ensures we meet both functional and non-functional requirements, preventing disruption to live systems. 
Figure 2: Example Hypercare Period
Our approach includes recommended logging levels and retention policies for the automation lifecycle, enabling audit tracking, error debugging, and live system monitoring. Logging levels can be customised to the force’s requirement, such as increasing logging levels where systems lack standard internal audit logs.

We have successfully developed processes on many police systems, including but not limited to:
- Niche (UA & DA)
- WebSTORM
- STORM (Smart & Steria)
- NFLMS
- HR systems (e.g., SAP and Agresso)
- Microsoft applications (Outlook, Word, Excel etc.)
- Browsers (Edge & Chrome) 
A core principle of our approach is prioritising Application Programming Interfaces (APIs) over user interface (UI) automation. APIs offer significant advantages in speed, efficiency, reliability, scalability, and security. Our API-First strategy reduces load and maintenance on live systems, as APIs are more resilient to UI changes and require minimal updates, ensuring long-term stability.
We also emphasise designing for reusability. With hundreds of reusable objects developed and deployed across multiple forces, we’ve built over 70 unique processes spanning a breadth of functions from back office, IT support, to front-line policing; all documented in a comprehensive Reuse Catalogue.
Our extensive experience includes creating end-to-end automations that integrate multiple systems. For example, the Firearms Licensing process leveraged integrations with NFLMS, NicheUA (primarily using Niche APIs), Outlook, and MS Edge to deliver a seamless, multi-system solution.
Deployment Options
There are multiple hosting options for an automation platform, the choice depends on the force's needs, including scalability, security, cost, performance and integration with existing systems. Consideration should be given to the operating and support model, and the services provided by different organisations to deliver the overall solution. We have strong relationships with many RPA SaaS providers and can offer support through alliance leads, even if we don't provide the solution. 
Hosting Options:
- On-Premises:
- Virtualisation offers flexibility, scalability, and dynamic resource allocation based on demand.
- Physical hardware must support the required virtual machines (VM) for all components.
- Hybrid Cloud
- Some components are hosted on a cloud platform.
- E.g. runtime resources may be hosted locally if cloud-based system integration is complex, while the app and SQL server are cloud-hosted.
- Cloud-Based (PaaS):
- Offers high availability, elastic scaling, and simplified infrastructure management.
- Reduces on-premises hardware overhead while ensuring scalability as operational requirements grow.
- Automation Provider Managed (SaaS):
- A fully managed solution offering rapid deployment and scalability without the need for infrastructure management.
- Providers: Blue Prism Cloud, UiPath Automation Cloud or IBM’s RPAaaS .
IBM will work closely with each force to determine the best option for their requirements. We also have experience working in complex environments, such as alliance forces, which require users to connect from multiple forests or domains.
IBM RPA as a Service
Our managed service is hosted on a secure cloud platform, providing the flexibility and scalability needed to manage forces automations whilst enabling the force to focus on their core business.
Development machines and robots are hosted at an IBM Cloud location or agreed alternative cloud provider, and we utilise a secure VPN connection to ensure seamless data exchange between our RPA system and the client's network. This connection can be established directly from the desktop to the App Server(s) using a client-to-server setup or between both sites using a server-to-server configuration, guaranteeing confidentiality and integrity of data while enabling smooth information flow.

Network & Connectivity
To ensure optimal performance, we recommend:
- Low-Latency Connections: Deploy on the same local area network for on-premises solutions.
- Load Balancing: Distribute workloads across multiple application servers to prevent bottlenecks once the number of runtime resources reaches 100.
- Resource Management: Log runtime resources in/out daily and restart weekly to minimise latency and ensure updates take effect.
- API-First Approach: Use APIs to reduce processing time and latency.
By following this approach, we have reduced the risk of application crashes and offline resources and improved overall performance.
Identity & Access Management
To ensure secure and efficient access management, we recommend:
- Active Directory (AD) Integration: Authenticate project personnel and robots using AD for seamless user management and roles-based access control.
- Single Sign-On (SSO): Implement SSO for all users accessing the chosen RPA tool to simplify access control and improve security.
- Remote Access: Provide IBM employees with force-issued laptops and VPN access for secure remote work.
- Multi-Factor Authentication (MFA): Follow MFA protocol where implemented but disable for robot accounts.
By implementing these measures, we can enhance security, operational efficiency, and user experience, while reducing the risk of password-related security incidents.
