As part of our proposal, IBM will be implementing IBM Maximo Scheduler.  This tool allows the user to visually manage, schedule, and assign work to resources across the organisation.  The work order from Maximo’s Work Management application will appear available for scheduling when a particular status is achieved. On the work order such things as skill set (e.g., certifications/qualifications needed to complete the work), service location/service address, priority and dates detailing when the work should be completed will be presented to the scheduler in the scheduling system. 
The user can manage upcoming work and assignments by creating schedules. By using the graphical view, maps, and calendars, the user can see the work and resource requirements that are in the schedule. For unplanned work, the user can respond to requirements by graphically assigning work to the appropriate labours (resources) and crews based on their availability and skill set. In addition, the user can create street-level routes for work lists to visually manage work progress on maps that show work, crews and labour based on their Maximo service addresses.

This suite of scheduling applications can also be set to schedules in advance or in real time.  If work needs to be rearranged or reassigned due to availability or work being completed later than estimated, the user will be able to accomplish this based on availability and skill set of the resources visible in the application.  Finally, the scheduling functions allows the work to automatically be optimised (pending the correct license) based on parameters configured in the system.  This assumes that all the correct data is completed on the work order in advance of the work being scheduled.
