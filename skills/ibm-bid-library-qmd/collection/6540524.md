NHSD have selected a range of environments and tools including AWS public cloud, Databricks, python, spark, RStudio, Splunk, Mauro and Collibra. The toolset proposed by NHSD is rich in functionality and covers the core functions for data pipelining and metadata management. This toolset should, as highlighted by NHSD, change and evolve over time. 
Although we have not seen the document entitled “Principles and Approach for SOW1”, we understand that NHSD intend to use a metadata and rules driven approach to data ingestion and the migration of the 200 datasets (starting with the scope of SOW1). IBM will work with NHSD to understand the role of each tool in the data optimisation process. We anticipate for this activity will be completed as SOW1 starts. As a proactive partner, we would bring suggestions for new type of tools to NHSD in good time to allow for proper procurement.
