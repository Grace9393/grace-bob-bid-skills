One of the biggest challenges will be the scale and diversity of the NHS Trust estate. This can range from under the desk service right up to state-of-the-art data centres (e.g. NHS Texas). We will create Trust-specific roadmaps, built on common patterns that will support and accelerate the Trust journey to the cloud, based on a key set of principles: 
- Cloud first, cloud native where possible 
- Build it once, automate and scale everywhere 
- Secure, resilient and evergreen by design 
- Standardise for simplicity 
- Support Digital Sustainability  
We have already done a level of analysis across the Digital and Trust application and technology estate and have defined repeatable patterns for treatment of those workloads based on likely Trust requirements, which will accelerate decision making and roadmap creation.
