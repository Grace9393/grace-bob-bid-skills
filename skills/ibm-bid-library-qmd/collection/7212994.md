As the solution will be hosted on WPD’s infrastructure, IBM will work with WPD during the cluster design phase outlined in question 13 to establish resiliency and back-up solutions that will ultimately be managed directly by WPD. 
The cluster design is a joint effort between WPD and IBM to agree the best possible fit in your environment and requirements.  IBM will make recommendation during this period in which WPD will sign up to or they can make alternative suggestions that will be agreed between both parties. Please reference question 13 on the traditional infrastructure architecture for Maximo Application Suit (MAS)
With regards specifically to the back-up solution, WPD should provide an online backup and recovery solution that meets their RPO/RTO requirements, though we recommend the following back-up regime:
- Backups should be performed seven (7) days a week. Full backups should be performed every Saturday. Incremental backups should be performed Sunday through Friday.
- All database transaction logs should be saved to the local filesystem as they are committed
- File system backups for all servers should be routed to a local Enterprise Backup Server for near line storage (quick retrieval)
- Production file system backups should be taken every 4 hours. Non-production file system backups should be taken every 12 hours
- Daily, all file system backups should be replicated to a remote (secondary) data centre
