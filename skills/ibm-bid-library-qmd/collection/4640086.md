IBM delivered DWP's shared service cloud platform, modernising 250+ applications and reducing OPEX. Monitoring workload performance and availability 24x7 uses CloudWatch and Beats to securely pass data to Logstash and Elastic (ELK). This combines with MI systems like Syslog, Nagios and Opsview on legacy systems. Data is available on 100+ Kibana dashboards. IBM provides AWS cloud hosting services for Philip Morris International. Continuous improvement includes AIOps (predictive maintenance through intelligent alerting), Next Best Actions (problem resolution) and self heal capabilities (reduces unplanned outages). Machine learning reduces AWS patterns from 700 individual to 20 core and 176 shared deployment patterns.
