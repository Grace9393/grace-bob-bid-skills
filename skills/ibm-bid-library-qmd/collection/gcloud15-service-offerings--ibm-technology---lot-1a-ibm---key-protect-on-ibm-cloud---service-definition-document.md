IBM Key Protect for IBM Cloud

Except as noted below, the terms of the IBM Cloud Service Description apply.

## 27 Cloud Service

1.1 	Offerings

The Client may select from the following available offerings.

1.1.1 	IBM Key Protect for IBM Cloud

IBM Key Protect for IBM Cloud is a multitenant cloud-based security service that provides key life cycle management for encryption keys and their versions ("Items") used by IBM Cloud services or Client-built applications.

1.1.2 	IBM Key Protect for IBM Cloud Satellite

IBM Key Protect for IBM Cloud Satellite is a single-tenant cloud-based security service that provides key life cycle management for encryption keys and their versions ("Items") used by IBM Cloud Satellite services or Client-built applications on IBM Cloud Satellite.
