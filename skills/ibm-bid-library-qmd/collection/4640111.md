For the HMRC customs declaration programme, IBM designed, built, deployed and now maintain an HMRC application for use by ports and shipping organisations called Inventory Linking. This provides APIs for those organisations to integrate their systems to link consignments and declarations with shipping movements, and to obtain clearances. The application is built to the Java EE 8 standards running on JBoss, utilising annotations, Managed Beans, JMS and Jakata RESTful Web Services. The micro-services are available as HTTP or queues, in JSON and XML. European standards for data types are used, and the entire application is transactional throughout to maintain consistency.
