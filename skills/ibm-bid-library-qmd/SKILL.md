# IBM Bid Library QMD

## Prerequisites

This skill reads the generated markdown collection at:

```text
$SKILL_DIR/collection/
```

The collection is materialised from the shared bid-library corpus:

```bash
make qmd-create-bid-library
```

That target rebuilds `skills/ibm-bid-library/corpus` from `all_docs.xlsx`,
replays durable custom documents from
`skills/ibm-bid-library/src/custom-documents.yaml`, then writes
`skills/ibm-bid-library-qmd/collection`.

For normal bid-library maintenance, add documents durably with
`make bid-library-add-document` and later run `make bid-library-rebuild-all`.
That refreshes SQLite, zvec, and QMD from the same accumulated corpus.

Use the Python wrappers in `$SKILL_DIR/scripts/`. They register the local
collection with QMD as `ibm-bid-library` when needed.

## Quick Reference

| Item            | Value                                      |
| --------------- | ------------------------------------------ |
| Corpus source   | `skills/ibm-bid-library/corpus`            |
| QMD collection  | `$SKILL_DIR/collection`                    |
| Collection name | `ibm-bid-library`                          |
| Source builder  | `skills/ibm-document-corpus-builder`       |
| Entries         | 2994 base entries plus durable custom docs |

## Commands

Inspect collection status:

```bash
uv run $SKILL_DIR/scripts/info.py
uv run $SKILL_DIR/scripts/info.py --json
```

Search:

```bash
uv run $SKILL_DIR/scripts/search.py "cloud migration" --json
uv run $SKILL_DIR/scripts/search.py "security architecture" --limit 10 --files
```

Retrieve a document:

```bash
uv run $SKILL_DIR/scripts/get.py 5234633 -l 40
uv run $SKILL_DIR/scripts/get.py qmd://ibm-bid-library/5234633.md
```

Optional vector embedding index:

```bash
uv run $SKILL_DIR/scripts/cache_models.py
```

For test isolation, set:

```bash
IBM_BID_LIBRARY_QMD_HOME=/tmp/ibm-bid-library-qmd-home
```

## Workflow

1. Run `make bid-library-rebuild-all` after adding durable custom documents.
   Use `make qmd-create-bid-library` only when refreshing QMD by itself.
2. Use `search.py` for QMD BM25 retrieval.
3. Use `get.py` with the document ID from search results to retrieve the
   markdown record.
4. Cite document ID, title, category, and `source_path` from the document
   frontmatter.

## Citation Requirements

Every reused bid-library result must include:

- Document ID / entry ID
- Title from frontmatter
- Category and tags when useful
- Source path, usually `docs/{id}.docx`

Example:

```text
Source: Bid Library Entry 5234633
Title: "6.Please provide evidence of data migration to cloud platforms"
Source path: docs/5234633.docx
```

## Notes

- This skill uses QMD over markdown generated from the canonical corpus. It does
  not own ingestion.
- Add documents through `ibm-document-corpus-builder` or
  `make bid-library-add-document`; then run `make bid-library-rebuild-all`
  when ready to refresh all retrieval targets.
- Do not edit `$SKILL_DIR/collection` directly. It is a generated output from
  `skills/ibm-bid-library/corpus`.
- Use `ibm-bid-library` for SQLite FTS comparisons and
  `ibm-bid-library-zvec` for zvec semantic retrieval comparisons.
