Maximo Start Centres will be used to track performance and various metrics throughout the work management team. A Start Centre in Maximo is the first page the user will see when logging into the system. It gives the user quick access to the tools and key performance indicators (KPIs) that will be used most frequently. The user can change the appearance of the Start Centre and can have multiple Start Centres based on their job role or roles. 
Each Start Centre is based on a template that has a security group assigned to it. When the user logs into the system, you see a Start Centre that is based on the template for the security group, which is role based. If the user belongs to more than one security group, they might see more than one tab, which represents a different Start Centre per security group.
A user with administrative rights can create and change templates, update portlets, and change the appearance of the Start Centre. A user with administrative rights can also control which portlets you see and can configure.  As part of the implementation, Start Centres will be defined by role as part of the security and Start Centre set up.  It is recommended to start with five or less generic Start Centre templates that can be used across the work management roles and then adjust based on the user demands.
The Start Centre functions and components are detailed below.  Please note, the user may or may not be able to make specific changes outlined below based on their security rights. 
- Start Centre portlets
A portlet is configurable window that provides quick access to applications and actions, and an at-a-glance view into data specific to the job function of an individual.
- Managing Start Centre templates
The portals and content that users see in the Start Centre depends on the Start Centre template that is assigned to their security group. A user with administrative rights can create Start Centre templates, modify or delete existing templates, and create templates that can be shown in multiple languages.
- Configuring Result Set portlets
The user can specify that rows in a Result Set portlet are coloured if they meet a condition. For example, the rows for the incidents with a priority of 1 are coloured in red. The user can also include related attributes in the result set. For example, you can display the given name and surname of a user, rather than their user ID.
- Changing the content and layout of the Start Centre
The user can change the content and layout of Start Centre pages. For each Start Centre, the user can specify the column layout, the portlets that they want to display in each column, the order of those portlets, and which portlets to remove from the columns. The user can also specify a name for the Start Centre, and this name will appear on the Start Centre tab.
- Specifying a default Start Centre
When the user has more than one Start Centre page available to them, the system displays tabs for each page.  The user can set which Start Centres appear as tabs on the Start Centre page, and which they want to open by default when you navigate to the Start Centre.
- Editing portlets in the Start Centre
The user can change the contents of a portlet in the Start Centre to make the information more useful to them. Changes can include adding information to a portlet, removing information from a portlet, changing the order of information in the portlet, and renaming the portlet.
- Updating Start Centres
When a system administrator notifies the user that changes have been made to their start centre template, they can update the Start Centre page.
