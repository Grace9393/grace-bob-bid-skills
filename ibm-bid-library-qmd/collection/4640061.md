IBM works with the Home Office and UK Police managing and administering data repositories, including a performant Oracle relational database cluster and a Hadoop Hbase database storing video-audio clips. Our experts have regularly used MYSQL relational databases to hold metadata for Hadoop clusters. We have administered many SQL-based databases, similar to AWS Redshift. HMRC and IBM are collaborating using IBM Watson Explorer and open source tools on AWS, integrating AI engines with a large Neo4J graph database to develop Intelligence and Investigation functions. IBM's Weather Company delivered a platform including a NoSQL database software for analysing text and video data.
