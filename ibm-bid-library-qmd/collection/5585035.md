On BP's journey to becoming a leading energy service provider, they must replace legacy systems and rapidly roll-out new global solutions. A team of 45 IBMers engineered with them a new full-stack customer experience platform using a large-scale Java and JavaScript microservice architecture. We used flexible React/HTML5 "micro frontend", reusable component libraries, and highly modular backend deployed in Docker containers on both AWS and Azure. The Git based CI/CD pipelines include automated BDD, e2e and performance testing utilising Cucumber, Selenium and JMeter. The new platform now hosts 30+ applications across the global BP estate; the first launch within 3 months.
