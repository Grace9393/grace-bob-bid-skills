Oracle Cloud Applications are provided with a reporting tool called Oracle Transactional Business Intelligence (OTBI) that is designed for all aspects of system user reporting including ad hoc and standard reports. Many standard reports are also supplied, and customer may download other reports from the Oracle Customer Connect report sharing tools. All data reported in this way is real time. 
Where needed Oracle also provides Fusion Analytics Warehouse (FAW) tooling which provides detailed business insight as data can be combined with 3rd party sources. This tool also includes AI and Machine learning based reporting and management information tooling.
Both tools combine seamlessly with pre-integrated data connectivity to Oracle Cloud Applications and can be used to create specific report and dashboards.
In addition, the FAW solution also include extract and load capabilities for Oracle EBusiness Suite.
IBM’s market leading predictive analytics and monitoring tools, utilising Watson AI to provide insights from data, can provide real-time guidance to the business and technical teams.
