Maximo
The Maximo Application Suite doesn’t require a local install and is accessed via a web browser. The current supported browsers are listed in the table below:

For Maximo Mobile (not included in this response but included here for reference), the application is designed to be adaptive, which means multiple versions of a page are available, each optimised for various device form factors.
Maximo Mobile is supported on the below platforms:
- iOS
- Android
Maximo Mobile should run on all devices if running the later versions of the platforms specified above.
 
SharePoint Online
SharePoint Online is part of Microsoft 365 (M365), which is a SaaS product on Microsoft Cloud. This does not have any operating system requirements. All services in M365, which includes SharePoint Online, are thin clients and only require a browser (like Safari, Google Chrome, Microsoft Edge, Mozilla Firefox) installed in a system which runs any operating system (like Windows, Mac OS, iOS, Android, etc.). 
 Mobile Operating Systems like iOS and Android have “Microsoft SharePoint” app in Apple App Store (https://apps.apple.com/us/app/microsoft-sharepoint/id1091505266) and Google Play Store (https://play.google.com/store/apps/details?id=com.microsoft.sharepoint&hl=en_IN&gl=US), respectively.

ArcGIS Online is provides a browser-based access for users to view GIS data and supports the following browsers:
- Google Chrome version 96 and later
- Microsoft Edge version 96 and later
- Mozilla Firefox version 97 and later
- Mozilla Firefox version 91 (ESR)
- Safari version 14 and later
As long as the system is capable of launching one of the above browsers, the user should be able to use the system.
If 3D data is required to be visualised by users through a browser using Scene Viewer, then the browser should support WebGL, have 8GB RAM and a GPU.  Graphics cards should have a minimum of 512mb of video memory but recommend 1GB.
Accessing 3D data is also supported in the following mobile devices:
- iOS Safari on iPhone XS, iPhone 11, iPhone 12, iPhone 13, iPad Pro 11-inch (2018) and later
- Android Chrome on Samsung S10, Samsung S20, Samsung S21, Samsung Tab S4 and later
