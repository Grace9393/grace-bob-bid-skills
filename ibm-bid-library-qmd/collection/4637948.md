We can provide different methods for tagging images to extract and use data from the image records having done this for many clients.
For a global energy company, we digested images of documents using an AI model that we trained to recognise key-value pairs and then store that data into structured rows.  For the EY Diligence Edge solution, we used tagging to extract all the data on a form into a record searchable store.  
Both these options also stored a link between the data extracted and the original image to allow further searching, retrieval or side by side comparisons.
