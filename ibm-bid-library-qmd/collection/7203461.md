The core Maximo solution (desktop) will need continuous connectivity to internal WPD servers in order to move to screen to screen or function to function within the system.  However, Maximo Mobile can be used both online and offline. When the field worker is online, the application is connected to the server continuously and data is synchronized in real time. When the field worker is offline, the application is disconnected from the server, but remains operational. The field worker can continue to work with secure data collections that are stored on the device. When the field worker’s device establishes connectivity to the server again, the data is synchronized back to the database automatically.
