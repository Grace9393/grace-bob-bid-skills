Our technical design, solutions, quality assurance, governance, review processes and delivery management are accredited to BS EN ISO/9001 and BS EN ISO/IEC 27001 27002.

In accordance with our 9001-derived quality standards, we tailor our internal review process for each engagement (and will do so for HMT). This considers the complexity and nature of HMT’s requirements and will define a right-sized and appropriate review process covering e.g. artefacts such as code and documents.

As an example, GUARDIAN is the RAF’s £80m project for a new Air Command and Control System that supports the detection and rapid response to potential hostile or suspect aircraft that pose a threat to UK sovereignty.

GUARDIAN is a safety-related system. Our software development process has been defined commensurately with this to produce software to Safety Integrity Level (SIL)1, as defined by BS EN 61508 and Def Stan 00-55.

Once the design is complete, the constituent objects are implemented. Code is produced in accordance with internal coding standards which are checked by a combination of static analysis tools and manual peer code reviews.

Static analysis checks all lines of code for compliance with industry-standard rules (e.g. for C++ against rules such as Universal Coding Standard and Meyers-Klaus items) and with the project coding standards.

Manual code reviews ensure that the code conforms to the coding standards; adequate error handling has been incorporated; code conforms to detailed design specifications, including the Human-Computer Interface specification and (if necessary) appropriate sections of the Interface Management Plan and no coding errors can be found.
