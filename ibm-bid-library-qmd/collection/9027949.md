IBM would propose staff to interact with the solution via remote access provided by SPEN (e.g. Citrix / Windows Virtual Desktop) or via their IBM-issued laptops and an SPEN provided secured network tunnel (e.g. VPN). All IBM computing devices use endpoint protection software and have mandatory endpoint controls and policies applied that ensure patches are present and secure configuration is maintained.
